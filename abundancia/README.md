# Abundancia con evidencia

Sistema personal para construir varias fuentes de ingreso con un ritual diario de enfoque.

| Pieza | Dónde | Para qué |
|---|---|---|
| Tablero | `tablero.html` (publicado como artefacto de Claude) | Declaración, cifra, fuentes de ingreso, ritual, WOOP, evidencias |
| Cuaderno | `notebooklm/` | Fuentes listas para subir a NotebookLM |
| `/notebooklm <tema>` | `.claude/skills/notebooklm` | Investiga y añade una fuente nueva al cuaderno |
| `/ritual-abundancia` | `.claude/skills/ritual-abundancia` | Sesión guiada de la mañana o de la noche |
| `/revision-semanal` | `.claude/skills/revision-semanal` | Revisión de 20 minutos y WOOP de la semana |
| `estratega-ingresos` | `.claude/agents` | Diseña y puntúa fuentes de ingreso |
| `coach-mentalidad` | `.claude/agents` | Declaración, afirmaciones creíbles, obstáculos |
| `verificador-evidencia` | `.claude/agents` | Comprueba afirmaciones y detecta estafas |

Principio: la visualización y la declaración sirven para dirigir la atención y sostener el trabajo. El dinero llega por lo que se vende, se conserva y se posee. Información general, no asesoramiento financiero.
